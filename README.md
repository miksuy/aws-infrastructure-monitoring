# AWS Infrastructure Monitoring & Alerting

## Overview

A personal cloud infrastructure project that automates the deployment and monitoring of an Ubuntu EC2 instance on AWS using Terraform.

The project uses Amazon CloudWatch to monitor infrastructure health and resource utilization, with automated email notifications through Amazon SNS when configured alarm thresholds are breached.

## Technologies

- Amazon Web Services (AWS)
- Terraform
- Amazon EC2
- Amazon CloudWatch
- Amazon SNS
- Ubuntu Linux
- Git and GitHub

## Planned Features

- Automated infrastructure provisioning with Terraform
- EC2 CPU utilization monitoring
- CloudWatch alarms
- Email notifications through Amazon SNS
- CloudWatch monitoring dashboard
- System and application log collection
- Infrastructure testing and documentation
